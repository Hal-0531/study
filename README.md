# 共通テスト地理・統計4択学習アプリ

提供された参考書の統計データ104表・556順位を使い、1回に1つの統計表だけ表示する4択学習アプリです。

## 使い方

1. 「分野」「出題モード」「出題する統計表」「検索」を選び、「この条件で出題」を押します。
2. 順位表の空欄に対応する4択から回答を選びます。通常演習では約半数の順位を出題します。
3. 全問の選択後、「確定・採点」を押すと、正誤と不正解時の正答を表示します。誤答は順位ごとに保存されます。
4. 「NEXT」で次の統計表へ進みます。「TRY：空欄を変える」で現在の統計表を解き直せます。
5. 「間違えた問題だけ」を選ぶと、まだ克服していない順位を復習できます。復習で正解すると克服済みになります。

既存の学習履歴形式（統計ID＋順位）を維持し、GoogleログインおよびFirebase Firestoreの自動同期と両立する設計です。同期にはFirebase側のGoogle Authentication、Firestoreのセキュリティルール、Pagesの承認済みドメイン設定が必要です。

## ファイル

- `index.html`：統計データと従来の学習記録管理
- `quiz.js`：新しい4択クイズのUI・採点・NEXT・復習
- `cloud-sync.js`：FirebaseのGoogle認証と学習記録の同期
- `firebase-config.js`：各自のFirebase設定
